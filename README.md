# BudgetApp

A private budgeting app for households. Import bank and credit card CSVs, auto-categorize spending, set budgets per category, and get a monthly report.

Status: early design. See [docs/initial-design.md](docs/initial-design.md) and the [Final Project Log](Final%20Project%20Log.md).

## Privacy
- This repo contains no real financial data. Demo data is synthetic (`samples/`).
- Real exports (`*.csv`, `data/`) and `.env` are gitignored.
- Copy `.env.example` to `.env` to configure.
